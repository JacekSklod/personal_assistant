Personal assistant application

This application was designed to act as another network manager + some other helpful functionality:
To set up ethernet interfaces, wireless interfaces, DNS.
Select Wireguard config files, show configuration, start and stop wireguard server and provide transmitted/received data counters.
Start/stop Tor server if there is appropriate script file and provide some basic metrics.
Execute Linux shell scrips for user and sudo.

Rust FLTK was used for GUI and Rust for logic code.
